# Proposal: Accessibility baseline to XAG/Deck numbers, and persistent battle alerts

Status: accepted (sw-luo, sw-opt, sw-9un)
From: craft-researcher, based on [../research/summaries/accessibility-guidelines-for-turn-based-tactics-games-questi.md](../research/summaries/accessibility-guidelines-for-turn-based-tactics-games-questi.md)

## The idea
Build the GDD's already-promised accessibility features to concrete, measurable standards (XAG v3.2 + Steam Deck Verified numbers) instead of "feature exists": first audit what we have at 1280×800, then close the two measured gaps — a Deck-readable text floor with resolution-independent 200% UI scale, and a persistent battle-alert panel with a notification-duration option (the WeGo parallel-battles gap no reviewed game solves for us). Screen narration and switch access stay deferred (expensive tail); we keep logical focus order and TTS-friendly string keys as cheap insurance.

## Why (evidence, with sources)
- **Colour-only identity is the genre's fatal flaw.** Advance Wars Re-Boot Camp's accessibility review fails it on identical unit shapes + faction-by-colour-alone; the reviewer won't recommend it to colourblind players. Our palette work (accepted art-styles proposal, sw-ijp.5 merged) addresses team colours; the audit checks the remaining colour-alone uses (cf. open bug sw-vld). https://caniplaythat.com/2023/06/02/advance-wars-12-re-boot-camp-accessibility-review/
- **Concrete numbers exist and are cheap to adopt.** Deck Verified: smallest text never below 9px character height at 1280×800, 12px recommended, readable at 30cm. XAG 101: body ≥18px at 1080p (≈13px at 800p), scale to 200% with no lost content, no forced two-axis scrolling. https://partner.steamgames.com/doc/steamhardware/compat · https://docs.xbox.com/build/game-principles/accessibility/xag-deep-dives/xag-101-text-display.md
- **Civ VI is the cautionary tale for scaling:** its UI scaler is greyed out at many resolutions; players resort to a +280% font mod. "Has a scale slider" is not the acceptance bar — "works at every resolution" is. https://steamcommunity.com/app/289070/discussions/0/3496509872208993569/
- **Turn timers are exempt as core mechanic (XAG 116), UI time limits are not:** toasts/dialogue must be extendable ≥10× or persist until dismissed; with parallel battles, alerts must be mirrored in a persistent glanceable panel, not only transient effects in a battle the player isn't watching (XAG 103/109, GAG "essential temporary info in the eye-line"). https://docs.xbox.com/build/game-principles/accessibility/xag-deep-dives/xag-116-time-limits.md
- **Shipped precedent:** ITB's colourblind mode swaps the red reticle for bright pink (players praise it); Wargroove ships two CVD modes + unit colour lock; Frostpunk scored 9.8/10 in a Deaf review for default-readable subtitles and an icon per event; Frostpunk 2 still draws colourblind complaints. https://pcgamecontrols.fandom.com/wiki/Into_The_Breach · https://gamecritics.com/aj-small/wargroove-review/ · https://caniplaythat.com/2020/01/16/deaf-game-review-frostpunk/ · https://steamcommunity.com/app/1601580/discussions/0/594010736965982779/

## Candidate beads
1. **Accessibility baseline audit at 1280×800.** Check the war room and Angelfall slice against report items 1–11 (text height at 800p, scale behaviour at 800p/1080p/1440p, untimed flag, remapping coverage, notification persistence, focus order, colour-alone uses), each marked done/partial/missing with file references and mapped to existing beads (sw-ll4.9/.10/.26, sw-vld, sw-ijp.5). Acceptance: note in `docs/swarm/research/notes/` with the item-by-item table; genuinely missing items written up as candidate follow-ups, not fixed here. Size: S. Type: task. Priority: 1.
2. **Deck-readable text floor + resolution-independent 200% UI scale.** Coordinate with sw-ll4.10/sw-ll4.26 first (audit bead 1 tells us what's left). Acceptance: at 1280×800 no body text below 12px character height (9px absolute floor); scale slider 100–200% reflows without two-axis scrolling at 800p, 1080p and 1440p; before/after screenshots at 800p attached. Size: M. Type: feature. Priority: 1.
3. **Persistent battle-alert panel + notification duration option.** Battle start/end and breaking alerts appear in a persistent, glanceable war-room panel that survives switching battles; toast duration slider (≥10× default) or persist-until-dismissed in options; setting persisted in `user://settings.cfg`. Presentation only — the panel reads battle events via signals, never mutates sim state (AGENTS.md §5). Acceptance: with two parallel battles, an alert raised in the unwatched battle is visible in the panel on return; duration setting survives restart. Size: M. Type: feature. Priority: 2.

## Rejected alternative
- **Screen narration / switch access now:** highest impact for blind and severe-motor players but L-cost (narrating a dense hex/battle UI is a project); defer to a post-MVP epic, mitigated by keeping focus order logical and string keys TTS-friendly from day one (report option C).
- **"Options menu exists" as the bar:** Civ VI shows a greyed-out scaler is worse than none — it ships the promise and breaks it. We adopt numeric acceptance instead.
- **Relitigating the ranked untimed lockout:** settled GDD decision (R2Q2); out of scope.
