# Proposal: Skirmish AI that reads as fair — disclosed profile card, cheese probes, fuzz difficulty presets

Status: accepted (sw-kif; beads 2-3 deferred to 2026-11-23 UTC — cap 8/8 on 11-22, p1 first; bead 3 depends on bead 1; same acceptance criteria)
From: craft-researcher, based on [summaries/skirmish-ai-opponents-that-read-as-fair-and-fun-questions-1-.md](../research/summaries/skirmish-ai-opponents-that-read-as-fair-and-fun-questions-1-.md) (draft by games-researcher, reviewed)

## The idea
Make the skirmish opponent legible and its difficulty honest, in three small steps: (1) show a profile card in skirmish setup with a difficulty label and the dials the AI actually uses; (2) measure how exploitable the shipped profiles are with scripted cheese probes before tuning anything; (3) offer difficulty presets built only on decision quality (the existing fuzz gene) and think-time — never unit stat buffs.

## Why (evidence, with sources)
- Fairness reads as "same rules, same information, visible intent". Into the Breach's AI is deliberately simple; difficulty is how often it picks the optimal vs second-best move, with real difficulty in maps and spawns. (https://archive.org/details/into-the-breach-ai ; https://media.gdcvault.com/gdc2019/presentations/Into%20the%20Breach%20Postmortem%20Final.pdf)
- Wesnoth configures AI personality as bounded, named data (`aggression=0.4`, `caution=0.25`, documented formulas, schedulable by time of day); difficulty is economic and disclosed (~25% gold/income per step, community rule of thumb). Even benign undisclosed scenario changes breed distrust. (https://wiki.wesnoth.org/AiWML ; https://steamcommunity.com/app/599390/discussions/0/3802776070756068823/)
- The top player complaints are hidden cheats and cheese, not weakness: Wargroove's AI attacks out of fog and ignores villages ("Would anyone play chess where the computer moves a piece 1 extra space?"); Total War players suspect undisclosed stat bonuses and later got behaviour difficulty split from AI stat modifiers — an explicit admission the axes differ. (https://steamcommunity.com/app/607050/discussions/0/1778261844039609181/ ; https://steamcommunity.com/app/1142710/discussions/0/3185737967878386431/ ; https://steamcommunity.com/app/1142710/discussions/0/5796774642235112803/)
- Frozen Synapse, our closest structural analogue (simultaneous plan-then-execute, no dice, symmetric rules), warns that perfectly testable plans create "perfection pressure" — keep tension in timers and reactions, not secrecy. (https://www.gamedeveloper.com/audio/postmortem-mode-7-games-i-frozen-synapse-i-)
- Code verified at review: all three core profiles (`data/packages/core/defs/profiles.json`) omit `fuzz` (=0, always optimal); `profile_controller.gd` already reads `fuzz` 0–100%, `fuzz_seed`, `think_ms`; `main_menu.gd` shows only name + feel text; `reinforcements()` is literally strongest-first; Aggressor weights `objective_control` 0.5 / `economy` 0.3 — the same shape as Wargroove's village blindness.

## Candidate beads
1. **Skirmish profile card: difficulty label + disclosed dials.** Skirmish setup shows per profile: the feel sentence (already there), a difficulty label, a handicap line ("none" today), fuzz % and think-time — all read from the same `controller_profile` data `ProfileController` consumes, so display can never drift from behaviour. Acceptance: GUT test asserts displayed values equal the profile's actual values (including defaults when keys are omitted); mock PNG at 800p; no gameplay change. Size: S. Type: feature. Priority: 1. GDD: 05 R7Q15/R7Q19; 01 pillars 2–3. Coordinate with sw-ll4.26 (menu/display pass) so the card uses the shared theme.
2. **Cheese-probe lab for shipped profiles.** A new `data/sim/labs/` lab runs scripted exploit scenarios (objective rush while the AI is engaged; repeated-position/target loops; commander fixation) against all shipped profiles headless via `hx sim lab`, reporting per-profile exploit success. Measure first, tune later; hard-code guardrails in curated profiles only after the probes show the hole. Acceptance: lab runs headless via `hx sim lab`; per-profile results recorded in the bead notes; no AI behaviour changed by this bead. Size: S (M if the lab format needs new scripting hooks — check `data/sim/labs/` first). Type: task. Priority: 2. GDD: 05 Shipped AIs/fitness; 01 pillar 2.
3. **Fuzz-based skirmish difficulty presets (no stat buffs).** Skirmish offers ≥2 difficulty presets that differ only in fuzz %/think-time (optionally composition), never unit stats; the card from bead 1 shows the active preset's values. Acceptance: same seed + preset replays identically (GUT determinism test); higher difficulty picks optimal orders measurably more often in a scripted scenario; ladder values flagged for playtest tuning, not settled here. Size: M. Type: feature. Priority: 2. GDD: 05 A1Q4; 01 pillar 2 (R1Q3). Depends on bead 1 for disclosure.

## Rejected alternative
Stat-buff difficulty sliders (Total War's old model): players read undisclosed buffs as cheating, and even disclosed ones split the audience; pillar 2 permits them only with full disclosure, and decision-quality + composition difficulty is the cheaper, fairer first lever. Also rejected: showing raw utility weights on the card — behaviour sentences at low verbosity keep it readable (report rec 1 trade-off).
